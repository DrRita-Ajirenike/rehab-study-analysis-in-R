# Learn R with Me: Rehabilitation Study Analysis

## About This Project

I am a medical doctor and MSc Global Health student developing my skills in R for health data analysis.

In this project, I revisit a rehabilitation study dataset used during my quantitative methods course. I share my own code, explain each step, and reflect on what I learn as I progress.

This repository contains my individual code and subsequent revisions.

## Part 1: Preparing and Exploring the Data

In this first part, I practise how to:

- Import an Excel dataset into R.
- Inspect the structure of the data.
- Calculate changes between entry and discharge measurements.
- Convert coded variables into labelled factors.
- Create salary categories.
- Produce boxplots and summary statistics.
- Calculate and interpret proportions within groups.

## What I Learned

- R is case-sensitive, so variable names and labels must be consistent.
- File paths need appropriate formatting when written in R.
- Factors give meaningful labels to categorical variables.
- length() counts observations, while sum() can count observations meeting a condition.
- Using prop.table(..., 1) calculates proportions within each row.

## Follow My Progress

I will add further analyses as I revisit the course exercises, including t-tests, linear regression, logistic regression, and survival analysis.

This is a learning project that I will continue to improve and also document.

The dataset is not included in this public repository. You can follow my code and explanations, but running the analysis requires access to the original data and an updated import path.
